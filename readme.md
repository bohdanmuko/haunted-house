# Будинок з привидами — міні-проєкт (Three.js + Vite)

Розширена версія проєкту з уроку «Haunted House».

## Запуск
```bash
npm install
npm run dev
npm run build
npm run preview
```
Папка `dist/` працює з будь-якого статичного хостингу (шляхи відносні): Vercel, GitHub Pages, Netlify.

## Обов'язкові пункти
| Вимога | Де в коді (`src/script.js`) |
|---|---|
| Геометрія | Box, Cone, Plane, Cylinder, Sphere, Icosahedron, Lathe, Shape → Crescent/Gable, InstancedMesh (паркан, плитки) |
| Імпорт текстур | `loadTexture` / `loadPBR`: webp (колір, ARM, нормаль, displacement, alpha) для землі, стін, даху, кущів, могил, дверей; `colorSpace`, `repeat`, `wrap` |
| Матеріали | MeshStandardMaterial з aoMap/roughnessMap/metalnessMap/normalMap/displacementMap/alphaMap; емісивне скло, гарбузи, лампа |
| Освітлення | Ambient, Directional («місяць», тіні), PointLight над дверима (миготить), 3 PointLight-привиди (тіні) |
| Анімація | рух привидів, миготіння ліхтаря й вікон, скрипуча двері туалету, «дихання» гарбузів, мерехтіння зірок, автообертання камери |
| Небо | `Sky` з повзунками, зорі, місяць зі світінням |
| Туман | `FogExp2` (щільність і колір — повзунки) |

## Що додано відносно уроку
- Не «кубичний» будинок: димар, фундамент, ґанок, рами дверей, вікна, ліхтар; гараж із секційними воротами, сарай із двосхилим дахом, вуличний туалет з місяцем на дверях.
- Паркан із хвірткою (стовпи, планки, штахетини — InstancedMesh), кам'яні плитки та бетонна доріжка до гаража, каміння, мертві дерева, гарбузи, кущі.
- Дерев'яні таблички з текстом (CanvasTexture) і процедурна текстура дерева.
- Могили трьох типів, розставлені випадково, але без перетину з будівлями.
- Звуки (Web Audio API, без файлів): вітер, гул, цвіркуни, скрип дверей, дзижчання ліхтаря в такт миготінню. Вмикаються кнопкою на екрані.
- Панель lil-gui (українською): небо, туман, всі світла, ліхтар, привиди (колір, швидкість, радіус кожного), повторення текстур, рельєф, камера, звук, пресети «Ніч / Сутінки / Пасмурний день».
- Екран завантаження з прогресом (LoadingManager).

Одиниця виміру: 1 = 1 метр. Рівень землі — y = 0.
